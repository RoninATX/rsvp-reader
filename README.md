# rsvp-reader

A small speed-reading utility. It flashes one word at a time in a fixed spot, with a single
red letter (the optimal recognition point) always landing in exactly the same place, so your
eyes never have to move across the page.

The technique is RSVP (Rapid Serial Visual Presentation) with ORP highlighting, as popularized
by Spritz.

**Status:** just getting started. First goal is a single-file HTML reader (paste text, press
play). Planned after that: pacing that slows on long words and punctuation, rewind with a
context view, and a way to pull in text from web pages.
